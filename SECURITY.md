# Security and disclosure policy

This is a public concept and website repository, **not** a repository for live contractor records, personal/participant information, privileged correspondence, keys or contract documents.

- Never commit tokens, API credentials, environment files, production URLs with embedded secrets, private data, assessments identifying firms, or nonpublic government/employer material.
- Report suspected vulnerabilities privately to the repository owner using GitHub's private vulnerability reporting feature **if it is enabled**. If unavailable, use a private communication channel already verified with the maintainer; do not post exploit details publicly.
- Open public issues only for non-sensitive bugs and documentation corrections.
- Do not deploy PR previews with secrets or connect a production domain without a specific owner release decision.
- If a disclosure involves sensitive government, contractual, or controlled information, follow the applicable originating organization's processes.

No security service-level agreement or bug bounty is offered.
